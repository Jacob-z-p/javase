# JDK 的安装及环境配置

> 该部分讲解 JDK 的安装及 Windows 的环境配置

到 Oracle 官网安装 JDK：https://www.oracle.com/java/ 。

安装好后，需要配置好环境变量，目的是可以在任意目录下编译运行 java 代码。

首先在系统变量中配置`JAVA_HOME`：

其中有 `javac` 用于编译，`java` 用于运行。

在 `cmd` 中测试一下是否能在任意目录下找到 JAVA：

![](./img/005.png)

>思考：为什么要配置 `JAVA_HOME`，而不是直接在 `Path` 中直接加入对应的 `bin` 目录？
>
>如果只是为了编译运行 java 代码，其实后者也可以。但是 `JAVA_HOME` 的主要作用是 **为其它开发环境指路**：
>
>- **构建工具**：Maven、Gradle 需要靠 `JAVA_HOME` 来定位 JDK。
>- **应用服务器**：Tomcat 等常常依赖 `JAVA_HOME` 来启动。
>- **IDE**：`IntelliJ IDEA` 等集成开发环境会读取它来配置项目 SDK。

# JDK 的安装目录

> 该部分讲述 JDK 的安装目录有哪些，分别的作用是什么

1. `bin`：该路径下存放了各种工具命令
2. `conf`：该路径下存放了相关配置文件
3. `include`：该路径下存放了一些平台特定的头文件
4. `legal`：该路径下存放了各模块的授权文档
5. `lib`：该路径下存放了工具的一些补充 JAR 包
